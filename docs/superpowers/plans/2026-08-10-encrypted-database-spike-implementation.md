# Encrypted Database Spike Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify the minimum Flutter encrypted SQLite spike required for Milestone 1.

**Architecture:** Create a Flutter app shell, then isolate encryption behavior behind a small data/platform boundary. Keep the spike separate from future production transaction schema so provider validation can be replaced or promoted cleanly.

**Tech Stack:** Flutter, Dart, `sqlite3` 3.x, SQLite3MultipleCiphers or SQLCipher provider, `flutter_secure_storage`, `path_provider`, Flutter tests.

## Global Constraints

- V1 platforms: iOS and Android.
- Core functionality must work without network.
- Accounting database must be encrypted.
- Generate at least a 256-bit database key using cryptographically secure randomness.
- Store the key only in iOS Keychain / Android Keystore backed secure storage.
- Do not store the database key in SharedPreferences or equivalent general key-value storage.
- Do not log SQL binding values, notes, amounts, keys, or full database paths.
- Database exists but key missing must not create a replacement key or overwrite the existing database.
- Milestone completion requires `git add`, `git commit`, and `git push`.

## File Structure

- `pubspec.yaml`: Flutter package dependencies and test dependencies.
- `lib/main.dart`: Minimal app shell and debug spike trigger surface.
- `lib/data/security/database_key_store.dart`: Database key abstraction and secure-storage implementation.
- `lib/data/security/database_key.dart`: Value object for the binary key.
- `lib/data/security/database_key_errors.dart`: Typed key-state failures.
- `lib/data/spike/encrypted_database_spike.dart`: Encrypted SQLite spike open/write/read/reopen flow.
- `lib/data/spike/encrypted_database_spike_result.dart`: Result and status types.
- `test/data/security/database_key_store_test.dart`: Key-generation and missing-key tests using a fake storage adapter.
- `test/data/spike/encrypted_database_spike_test.dart`: Non-platform logic tests for state transitions.
- `docs/verification/milestone-1-encrypted-database.md`: Manual iOS/Android verification procedure and results template.
