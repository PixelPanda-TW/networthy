## Clear-all-data behavior

Custom category metadata is stored only in the encrypted Drift database.
`ClearLocalData.clear()` deletes the database file plus WAL/SHM/journal files,
so custom category rows are removed with the rest of local data. On the next app
start, bootstrap creates `DriftCategoryRepository` and calls
`ensureBuiltInCategoriesSeeded()`, which restores built-in categories
idempotently.

No extra clear-data production code is required for v0.2.0 because there is no
category metadata outside the encrypted database file.

## Manual script

1. Open Settings → 分類管理.
2. Add expense category `飲料`.
3. Add child category `咖啡` under `飲料`.
4. Add a transaction with `飲料 / 咖啡`.
5. Confirm overview and records show `飲料 / 咖啡`.
6. Rename `咖啡` to `拿鐵`.
7. Confirm historical transaction display updates to `飲料 / 拿鐵`.
8. Archive `拿鐵`.
9. Confirm new transaction form no longer offers `飲料 / 拿鐵`.
10. Confirm old transaction still displays `飲料 / 拿鐵（已封存）` when editing.
11. Clear all data and restart.
12. Confirm built-in categories appear again.
